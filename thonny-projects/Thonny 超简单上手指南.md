# Thonny 超简单上手指南（初学者版）

这是一份专为**零基础**新手准备的指南，跟着做就能用 Thonny 写出并运行你的第一个 Python 程序！

---

## 一、Thonny 是什么？

**Thonny** 是一个专门为初学者设计的 Python 代码编辑工具。它最大的优点就是**简单**——打开就能用，不需要复杂的配置。

适合用来：
- 学习 Python 语法
- 给开发板（如 Raspberry Pi Pico、ESP32）写 MicroPython 程序

---

## 二、安装 Thonny（2分钟）

### 2.1 下载

1. 打开官网：**https://thonny.org/**
2. 网站会自动识别你的电脑系统（Windows / Mac / Linux），直接点击中间的下载按钮

### 2.2 安装

**Windows 用户**：
1. 双击下载的 `thonny-xxx.exe` 文件
2. 一路点击 **Next** → **Install** → **Finish**
3. 安装完成后，桌面会出现 Thonny 的图标

> 💡 **新手提示**：下载时选择 "Installer with 64-bit Python" 这个版本，它会**连 Python 一起装好**，不需要额外安装任何东西。

**Mac 用户**：拖动 Thonny 图标到 Applications 文件夹即可。

---

## 三、认识 Thonny 界面（1分钟）

打开 Thonny 后，你会看到这样的界面：

```
┌─────────────────────────────────────────────┐
│  菜单栏                                      │
├───────────────────┬─────────────────────────┤
│                   │                         │
│   编辑区          │      Shell 区           │
│   （写代码的地    │   （显示运行结果）       │
│   方）            │                         │
│                   │                         │
└───────────────────┴─────────────────────────┘
```

- **上半部分**：编辑器，在这里写代码
- **下半部分**：Shell（也叫交互式环境），可以直接输入命令并立即看到结果
- **顶部按钮**：绿色的“运行”按钮（最常用！）、保存、打开等

---

## 四、运行第一个程序："Hello World"（1分钟）

### 4.1 写代码

在编辑器（上半部分）里输入这一行：

```python
print("Hello World!")
```

### 4.2 保存文件

1. 点击**保存图标**（左上角的软盘图标）
2. 选择一个文件夹，把文件命名为 `hello.py`
3. 点击保存

### 4.3 运行程序

点击**绿色的运行按钮**（或者按键盘上的 **F5**）

### 4.4 看到结果

在下半部分的 Shell 区，你会看到：

```
Hello World!
```

🎉 **恭喜！你已经成功运行了第一个 Python 程序！**

---

## 五、用 Shell 做计算器（30秒试试）

Shell 区可以直接当计算器用。点击 Shell 区，在 `>>>` 后面输入：

```python
>>> 1 + 2
3

>>> 10 * 5
50

>>> print("你好")
你好
```

每输入一行，按回车就能立刻看到结果。这对于**快速测试小段代码**非常方便。

## 六、给开发板写程序（以 Pico W 为例）

如果你想用 Thonny 给 **Raspberry Pi Pico W** 或 **ESP32** 这类开发板写程序，需要先配置一下。

### 6.1 连接开发板

用 USB 线把开发板连接到电脑。

> ⚠️ **注意**：如果是第一次用 Pico，需要先按住板子上的 `BOOTSEL` 按钮再插 USB，把 MicroPython 固件装进去。

### 6.2 配置解释器

1. 点击菜单栏：**运行** → **配置解释器**
2. 在 "解释器" 选项卡中：
   - 选择 **MicroPython (Raspberry Pi Pico)** 或 **MicroPython (ESP32)**
   - 端口选择 "自动检测" 或出现的那一个
3. 点击 **确定**

### 6.3 写一个控制 LED 的程序

把下面这段代码复制到编辑器里：

```python
from machine import Pin
import time

# 初始化板载 LED
led = Pin("LED", Pin.OUT)

while True:
    led.toggle()      # 翻转 LED 状态
    time.sleep(0.5)   # 等待 0.5 秒
```

点击**运行**，开发板上的 LED 就会开始闪烁！

## 八、常见问题

### ❌ 问题1：点运行后没反应
**解决方法**：
- 先保存文件（`Ctrl + S`）再运行
- 检查代码有没有语法错误（左边会显示红色的 ×）

### ❌ 问题2：找不到开发板的端口
**解决方法**：
1. 检查 USB 线是否插好
2. 在 **配置解释器** 里重新选择一次端口
3. 尝试换一根 USB 线（有些线只能充电，不能传数据）

### ❌ 问题3：写中文时显示乱码
**解决方法**：
- 在文件**第一行**加上 `# -*- coding: utf-8 -*-`
