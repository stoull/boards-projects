# Arduino 超简单上手指南（初学者版）

这是一份专为**零基础**新手准备的指南，跟着做就能让 Arduino 跑起来！

---

## 一、你需要准备什么？

### 硬件（实物）
| 物品 | 说明 | 大概价格 |
|------|------|----------|
| **Arduino 开发板** | 推荐买 **Arduino Uno**（最经典的型号，教程最多） | ¥30-50（国产版） |
| **USB 数据线** | 方口 USB 线（打印机那种线），注意不是手机充电线 | ¥5-10 |
| **电脑** | Windows / Mac / Linux 都可以 | — |

> 💡 **新手提示**：买开发板时，让商家送一根 USB 线，很多新手卡在这一步。

### 软件（免费）
- **Arduino IDE**（官方开发软件）

---

## 二、安装软件（5分钟）

### 下载 Arduino IDE
1. 打开官网：`https://www.arduino.cc/en/software`
2. 根据你的系统下载：
   - Windows 选 `Windows Win 10 and newer`
   - Mac 选 `macOS Intel` 或 `Apple Silicon`
   - Linux 选对应的版本

### 安装步骤（Windows 示例）
1. 双击下载的 `.exe` 文件
2. 一路点 **"I Agree"** → **"Next"** → **"Install"**
3. 等待安装完成，点 **"Finish"**

> ⚠️ **注意**：安装过程中如果弹出“安装驱动”的提示，一定要点“允许”或“始终安装”。

---

## 三、连接开发板（2分钟）

### 步骤
1. 用 USB 线连接 Arduino 和电脑
2. 观察开发板上的**绿色电源灯**是否亮起
   - ✅ 亮了 → 正常
   - ❌ 没亮 → 检查 USB 线是否插紧，或者换个 USB 口

---

## 四、配置 Arduino IDE（2分钟）

### 4.1 打开 Arduino IDE
安装完成后，桌面会有 Arduino 图标，双击打开。

### 4.2 选择开发板型号
- 菜单栏：**工具** → **开发板** → **Arduino AVR Boards** → **Arduino Uno**

（如果你用的是其他型号，就选对应的）

### 4.3 选择端口（最关键的一步！）
- 菜单栏：**工具** → **端口** → 点击出现的 **COMx**（Windows）或 **/dev/cu.usbmodemxxx**（Mac）

> 💡 **怎么知道选哪个？**
> - 先不插 Arduino，打开 **工具** → **端口**，记下有哪些选项
> - 插上 Arduino，再次打开 **工具** → **端口**
> - **新出现的那一个**就是你的 Arduino！

---

## 五、运行第一个程序：Blink（LED闪烁）

### 5.1 打开示例程序
- 菜单栏：**文件** → **示例** → **01.Basics** → **Blink**

这时会自动打开一个新窗口，代码大概是这样的：

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```

### 5.2 上传到开发板
1. 点击左上角的 **→ 箭头按钮**（上传按钮）
2. 看 IDE 底部黑色窗口，会显示：
   - `Compiling sketch...`（编译中）
   - `Uploading...`（上传中）
3. 等待底部显示 **"Done uploading"**

### 5.3 见证奇迹！
- 上传成功后，Arduino 板子上**自带的 LED 灯**会开始闪烁
- 亮 1 秒 → 灭 1 秒 → 亮 1 秒... 🔄

🎉 **恭喜！你的 Arduino 已经正常工作了！**

## 六、代码超简单解释（不用记，看一眼就懂）

| 代码 | 是什么意思 |
|------|------------|
| `pinMode(LED_BUILTIN, OUTPUT);` | 告诉 Arduino：我要用这个引脚来**输出**信号 |
| `digitalWrite(LED_BUILTIN, HIGH);` | 给这个引脚**通电**（灯亮） |
| `delay(1000);` | **等 1 秒钟**（1000 毫秒） |
| `digitalWrite(LED_BUILTIN, LOW);` | 停止通电（灯灭） |
| `loop()` 里面的代码 | **不断重复执行**（亮→等→灭→等→亮→等...） |

> 🔑 **记住这两个就够了**：
> - `setup()` → 只执行一次（做准备工作）
> - `loop()` → 代码在这里面不断循环执行

## 七、常见问题解决

### ❌ 问题1：上传时报错 "Serial port not found"
**解决方法**：
1. 检查 USB 线是否连接牢固
2. 检查 **工具 → 端口** 有没有选中正确的端口
3. 换一根 USB 线（有些线只能充电，不能传数据）

### ❌ 问题2：编译时报错 "Board not found"
**解决方法**：
- 检查 **工具 → 开发板** 是否选对了（Arduino Uno 就选 Arduino Uno）

### ❌ 问题3：端口选项是灰色的，点不了
**解决方法**：
1. 先插上 Arduino
2. 等 5 秒让电脑识别
3. 如果还是灰色，重启 Arduino IDE

### ❌ 问题4：上传时一直卡在 "Uploading..."
**解决方法**：
- 拔掉 USB 线，等 3 秒，重新插上，再试一次
