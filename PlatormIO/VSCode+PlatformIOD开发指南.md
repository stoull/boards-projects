#### VS Code 中安装PlatformIOD IDE

1. 在VS Code中搜索`PlatformIOD IDE` (一个黄色的蚂蚁头在圆圈中)，点击安装
2. 安装完成后需要重启一下VS Code
3. 点击VS Code左边插件列表中的（PlatformIO）黄色圆圈中的蚂蚁头的图标。要以看到导航栏有QUICK ACESS的PlatformIO菜单
4. PlatformIO菜单里，主要有PIO Home, Open, PIO Account, Libraries等选项。
4. 点Open，可以进行创建新的项目，或者导入Arduino项目等，根据板子选择对应的板子固件，默认项目在 `~/Documents/PlatormIO`目录下
5. 点Libraries可以对当前项目进行库管理
6. PROJECT TASKS菜单中有，Build, Upload, Monitor等操作，或者在最底部有对应的快捷按键 -> (上传到板子) ✓（构建）一个插头的符号（串口监听）
